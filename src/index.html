WeChaser 和时光脉络是什么？What are WeChaser and Shiguangmailuo?

WeChaser 是一家企业 AI 中间件公司，主要服务中国制造企业。旗舰产品「时光脉络」是一个企业知识中间件：把图纸、工艺文件、SOP、客户档案、邮件等资料整理成带出处的知识层，供飞书 AI、钉钉 AI、Claude 或企业自研 Bot 通过 MCP / CLI / REST 调用。它本身不做生成，只提供可追溯的“原料”。

WeChaser is an enterprise AI middleware company focused on Chinese manufacturers. Its flagship product, Shiguangmailuo, is a knowledge middleware layer: it turns drawings, process documents, SOPs, customer records and email into a cited knowledge layer that Lark AI, DingTalk AI, Claude or in-house bots call via MCP / CLI / REST. It does not generate prose itself — it supplies traceable raw material.

和飞书知识问答、Dify、FastGPT 这类工具有什么区别？How is this different from Lark Q&A, Dify or FastGPT?

飞书/钉钉自带的知识问答主要覆盖平台内的文档；Dify、FastGPT 是需要自己搭建和调优的开源 LLM 应用平台。WeChaser 交付的是一个已经接好企业多源数据（文件、图纸、邮件、业务系统）、带权限和溯源、并由我们陪跑到员工真正在用的方案，同时可以被任意 AI 工具调用。详见方案对比。

Built-in Lark/DingTalk Q&A mainly covers documents inside that platform; Dify and FastGPT are open-source LLM app platforms you build and tune yourself. WeChaser delivers a working setup already wired to your multi-source data (files, drawings, email, business systems), with permissions and citations, run with you until adoption is real — and callable from any AI tool. See the comparison.

数据会离开企业网络吗？能私有化部署吗？Does our data leave our network? Can it run on-prem?

可以完全私有化。知识库、向量库和文件原件都部署在你自己的服务器上（docker-compose 交付）。生成模型二选一：本地 GPU 部署开源模型，可完全断网运行；或使用你批准的国内合规 API。

Yes, fully on-prem. The knowledge base, vector store and file originals run on your own servers (delivered via docker-compose). For generation you choose: open-weight models on local GPUs, fully air-gapped, or a compliant API you approve.

大概多少钱？How much does it cost?

第一阶段 2 周调研免费。之后按里程碑付款，咨询、集成接入、文档运营三类服务的典型区间在 ¥30K–¥350K，GPU / 存储等基础设施按实际采购、不计入报价。详见报价页。

The 2-week discovery phase is free. After that, milestone-based payments; typical ranges for consulting, integration and document ops are ¥30K–¥350K. Infrastructure (GPU / storage) is procured at cost and excluded. See pricing.

多久能用上？How long until it's in use?

典型周期 12 周：2 周调研、4 周接入、6 周单条业务线试点，之后把试点模板推广到其他业务线。

A typical cycle is 12 weeks: 2 weeks discovery, 4 weeks integration, 6 weeks pilot on one business line, then rollout of the pilot template to other lines.

支持接入哪些工具？Which tools does it integrate with?

协作工具支持飞书、钉钉、企业微信、Slack；AI 工具（如 Claude、飞书 AI、钉钉 AI 或自研 Agent）通过 MCP、CLI 或 REST API 调用。员工不需要换工具。

Collaboration: Lark, DingTalk, WeCom and Slack. AI tools (Claude, Lark AI, DingTalk AI or your own agents) call it via MCP, CLI or REST API. Nobody has to switch tools.

AI 答错了怎么办？What if the AI gets it wrong?

每条回答都附带原始文件出处，可以一键核对；证据不足时系统会拒答，而不是编一个答案。价格、交期、工艺变更这类决策始终由人确认，AI 只提供底稿和依据。

Every answer carries a link to its source so it can be checked in one click, and the system refuses when evidence is insufficient instead of making something up. Decisions like price, lead time or process changes are always confirmed by a person — the AI supplies the draft and the evidence.
